# Greenden# Greenden 🌿

Greenden is a responsive, modern e-commerce and showcase website designed for sustainable, eco-friendly plants and gardening products. The project features a clean layout, a dynamic product collection, and a user-friendly interface optimized for all screen sizes.

## 🚀 Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Product Showcase:** A visually appealing catalog displaying various eco-friendly plants and gardening items.
- **Interactive Search & Filter:** Smooth navigation and filtering options to help users find the perfect plants.
- **Contact Form:** A functional contact section for customer inquiries and sales.
- **Modern Styling:** Built with utility-first CSS for high performance and clean UI alignment.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure for web content.
- **Tailwind CSS:** For fast, custom, and responsive UI components.
- **JavaScript (ES6):** Powering interactive elements like mobile responsive navigation menus and search filtering.
